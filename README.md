# quiz-app
Simple Python console-based quiz app
This is a simple console-based quiz app built using Python.  
It asks the user multiple-choice questions and shows the final score.

## How to Run

- Save the script as `quiz_app.py`
- Run it in any Python environment (like Pydroid 3)

## Topics Covered

- Lists & dictionaries
- Loops
- Conditional logic
- User input
